# Support de soutenance

Deck présenté à l'oral du jury RNCP. Écrit en [Marp](https://marp.app/) (Markdown → HTML/PDF), rendu automatiquement par la CI à chaque push.

- **Durée cible** : ~20 min de présentation + démo
- **Format** : 28 slides, 16:9
- **Auteur** : Arthur Lagenèbre
