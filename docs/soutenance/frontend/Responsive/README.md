# Captures responsive

> 11 pages × 3 viewports (Desktop 1440×900, iPad 768×1024, iPhone 12 Mini
> 375×812) — preuve visuelle du design responsive pour le **Bloc 1**
> (HTML/CSS/JS responsive) et le **Bloc 3** (Angular adaptatif).

Les captures sont prises sur le build de prod (`npm run build` + `npm run
serve:ssr`). Pour la procédure de prise de captures, voir
[Audit Lighthouse — template](../audit/01-lighthouse-template.md).
